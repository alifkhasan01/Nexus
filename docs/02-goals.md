# Goals

## Product goals

- Provide a cohesive Wayland desktop experience.
- Make common desktop actions fast and discoverable.
- Offer a polished macOS-inspired workflow without requiring a full desktop environment.
- Work well with tiling Wayland compositors.
- Support multi-monitor setups.
- Keep configuration understandable.
- Make modules independently maintainable.

## Engineering goals

- Small, composable QML components.
- Thin UI-to-service boundaries.
- Clear backend interfaces.
- Testable system services.
- Minimal duplicated state.
- Documented public interfaces.
- Reproducible development and packaging.
