# Vision

## Vision statement

Create a modern, beautiful, modular and performant desktop shell for Linux Wayland desktops.

## Principles

### Native Linux

Prefer existing Linux infrastructure over reimplementing it.

### Modular

Every major feature has a clear module or service boundary.

### Separation of concerns

QML owns presentation and interaction. Backend services own system integration and complex state.

### Configurable

Users can customize appearance, layout, behavior, modules and animations.

### Event-driven

Prefer subscriptions and events over aggressive polling.

### Performant

Avoid unnecessary processes, repeated IPC calls, excessive polling and duplicated state.

### Consistent

Components share the same typography, spacing, radius, elevation and animation rules.

### Accessible

Keyboard navigation, readable contrast, reduced motion and predictable focus behavior are first-class concerns.
